# Project Rules for Codex

## General
- Before editing, inspect the relevant files and understand the current structure.
- Do not delete existing functionality unless explicitly requested.
- Prefer small, focused changes.
- Keep code comments concise and useful.

## Change log
After every completed coding task, update `log.md`.

Each new entry must include:
- Date
- Task goal
- Changed files
- Approximate added / modified / removed lines
- Added functionality or content
- Removed functionality or changed behavior
- Verification steps
- Known limitations or TODOs

Do not overwrite old log entries. Append a new entry.
