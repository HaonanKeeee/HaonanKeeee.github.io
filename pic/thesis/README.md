# Thesis image sources

These assets are resized WebP exports from Haonan Ke's master's thesis, *Heterogeneous Acceleration of Vision-Language-Action Models on an Edge SoC-FPGA Platform*, submitted on 2 October 2026.

| Asset | Original source |
| --- | --- |
| `platform.webp` | Actual experimental-platform photograph: `A1_Thesis/figures/system.png`. |
| `architecture.webp` | Final thesis Figure 7.1, printed page 66: compressed-model deployment across the CPU, NPU, and FPGA. |
| `results.webp` | Final thesis Table 7.5, printed page 73: command throughput, dequeue-to-command latency, and output information age over 180 post-warm-up frames. |
| `demo.webp` | Actual cup-following photograph: `A1_Thesis/figures/final_exact_original_objects_2.png`, used in Figure 7.4(a). |

The architecture and results images preserve the original figure/table content and captions. Camera-to-command timing ends at the software command sink; actuator response is evaluated separately. Only these image exports are included here; the signed thesis PDF is not distributed.
